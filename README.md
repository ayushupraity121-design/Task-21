# Task 21: Missing Value Analysis

## 📌 Project Overview
This project focuses on identifying missing data in a given dataset, calculating the total count and percentage of missing values per column, and identifying features that require treatment prior to machine learning workflows.

---

## 🎯 Objectives
- Understand the importance of inspecting missing data before building machine learning models.
- Perform column-wise missing value identification using Pandas.
- Output actionable summary reports identifying attributes needing imputation or cleaning[cite: 1].

---

## 🛠️ Tools & Technologies Used
- **Python** (v3.x)[cite: 1]
- **Pandas**: For data manipulation and missing value analysis[cite: 1]
- **NumPy**: For numerical utilities[cite: 1]
- **Jupyter Notebook / VS Code**: Workspace environment[cite: 1]

---

## 📂 Deliverables Covered
1. **Missing-Value Summary**: A consolidated table containing missing counts and percentages per column[cite: 1].
2. **Column-Wise Missing Counts**: Precise counts using `isnull()` / `isna()` and `sum()`[cite: 1].
3. **Identification of Columns Requiring Treatment**: Filtered list of feature columns requiring imputation or deletion[cite: 1].
